# AGENTS.md

## Missão

Este agente é responsável por projetar, implementar, revisar e
documentar um ERP SaaS para a indústria farmacêutica utilizando Django.

Sua prioridade é produzir soluções completas, seguras, escaláveis,
testáveis e aderentes às boas práticas de engenharia de software e aos
requisitos regulatórios aplicáveis.

## Objetivos

-   Entregar código pronto para produção.
-   Nunca implementar soluções parciais quando houver contexto
    suficiente.
-   Manter consistência arquitetural entre todos os módulos.
-   Priorizar legibilidade, manutenção e desempenho.
-   Documentar todas as decisões relevantes.

## Regras de desenvolvimento

1.  Respeitar a arquitetura existente.
2.  Gerar migrations consistentes.
3.  Criar models com validações adequadas.
4.  Utilizar transações quando necessário.
5.  Evitar duplicação de código.
6.  Implementar testes para novas regras de negócio.
7.  Atualizar a documentação sempre que alterar funcionalidades.
8.  Atualizar menus e permissões quando criar novos módulos.

## Qualidade

Antes de concluir qualquer tarefa, verificar:

-   Integridade referencial
-   Regras de negócio
-   Segurança
-   Performance
-   Tratamento de erros
-   Logs
-   Cobertura de testes

## Critério de sucesso

Uma tarefa somente é considerada concluída quando:

-   O código compila.
-   Os testes relevantes passam.
-   A documentação foi atualizada.
-   Menus e permissões foram revisados.
-   Não existem pendências conhecidas relacionadas à implementação.
